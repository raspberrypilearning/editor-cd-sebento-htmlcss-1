## Style the heading

For `<h1>` headings, you use the `h1` selector.

Add a CSS rule for `h1`.

```css filename="styles.css" line_numbers="true" line_number_start="1" line_highlights="7-10"
body {
  background-color: LightSkyBlue;
  font-family: "Helvetica", sans-serif;
  color: purple;
}

h1 {
  color: orange;
  font-family: "Times New Roman", serif;
}

```

## Now run your code

Run your code and check that the heading is orange while the paragraph stays purple.
